# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

In short: be welcoming and patient with newcomers, keep feedback about the work rather than the person, and do not harass, insult or publish anyone's private information. These expectations apply to issues, pull requests, reviews, Discussions and any other project space.

## Reporting

If someone's behaviour concerns you, contact the maintainer privately through [GitHub's private vulnerability / advisory form](https://github.com/senanurcetin/offline-jsonl-workshop/security/advisories/new) or use GitHub's built-in "Report content" option. Please do not raise conduct reports in public issues. Reports are handled confidentially.

## Enforcement

The maintainer may edit or remove comments, close threads, or block participants whose behaviour breaks this code, following the enforcement guidelines of the Contributor Covenant.
